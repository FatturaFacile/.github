# FatturaFacile `.github`

Default community health files for the [FatturaFacile](https://github.com/FatturaFacile) organization. GitHub applies the files in this repository to every organization repository that does not define its own version.

This repository contains no code, so there is nothing to build, run, test or lint.

## Contents

| File | Purpose |
| :--- | :--- |
| `PULL_REQUEST_TEMPLATE.md` | Default pull request template (summary, how to test, checklist) |
| `FUNDING.yml` | Funding links shown in the "Sponsor" button of the organization repositories |
| `README.md` | This file |

A repository can override any of these by adding its own copy (for example `.github/PULL_REQUEST_TEMPLATE.md`); GitHub then uses the repository's version.

## Branching

`main` is the only branch and the default. Open pull requests against `main`. There is no CI workflow in this repository.
